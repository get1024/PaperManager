## 代码整理

- 原 2,003 行 `NativeLibraryView.swift` 缩至 455 行，分离侧栏、表格、共享单元格、工具栏路由及按需几何诊断。检查器选区、hover、直接编辑实现保持原有行为。
- 新增纯数据 `LibraryQuery`，文献筛选只做一次目标排序，复用文集后代、路径和标签索引；侧栏数量一次遍历计算，同一篇文献在共同祖先中只计一次。
- Local API 重复配置复用待启动或活动监听，监听替换隔离旧回调；停止时释放已接收连接，防止半包请求残留。
- 菜单保留活动窗口路由，删除没有发送方的 8 条旧通知路由及伪添加节点分支。
- 移除 3 个无效设置和 6 个零引用函数。旧 JSON 额外键可读取，读取不重写文件；再次保存时去掉废弃键。仍有实际迁移用途的旧字段保留。
- 新增 `scripts/clean.sh`，统一当前缓存清理入口；默认保留最新测试日志。
