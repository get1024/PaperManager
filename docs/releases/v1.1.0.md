# PaperManager 1.1.0

- 修复蓝色选中行的文字颜色，标题和其他文字列统一使用白色。
- 在标题、作者、引用键右侧增加 PDF 页面预览与 macOS 原生翻页按钮。
- 增加论文阅读时间与进度：手动开始／暂停，外部阅读器兼容，休眠暂停；支持确认已读至预览页。
- 更新 README 架构审核、模块入口与贡献流程，移除指定的历史介绍段落。
- 纳入工作区已有的评分即时同步、导入重复项处理、查询缓存、持久化与元数据回归修复。

阅读时间是手动会话时间；外部阅读器的页码、关闭和空闲状态不自动跟踪。预览翻页不会自动增加进度。发行包为临时签名，未经过 Apple 公证。

## 发布验证

- 本地完整 `scripts/test.sh all`：core 16 组、UI 9 组、AX 2 组、扩展 UI 3 组均完成。初次 WindowGroup 测试因系统原生按钮横坐标 114 与旧硬编码 110 不符而失败；改用真实窗口控件间距后，复测 32 阶段通过。
- 阅读／预览专项最终 33 项通过；评分交互 53 项通过。
- Xcode 工程成员检查：44 个 App Swift 源文件、4 个独立 CLI 源文件，资源和嵌入关系通过。
- macOS 实际应用隔离副本：白色选中文字、首页缩略图、翻到第二页、手动标记 2/66=3%、开始／暂停、切换论文保持原计时归属，以及返回首页均已检查。正式 72 篇文库 SHA-256 未变。
- 本地优化 app 构建与严格签名验证；GitHub Actions 另行执行 SwiftPM 和完整 Xcode 构建、DMG 打包。
- README 的三张演示图从生产组件和合成数据重新生成，主界面已目视检查。

本地仅安装 Command Line Tools，完整 Xcode 验证由发布 CI 执行。人工界面核验为浅色外观，未声称像素级全主题一致。
