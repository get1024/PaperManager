# PaperManager 1.1.1

原生 macOS 文献管理器，将文献、笔记、PDF 附件与引用放在同一个本地工作空间。

## 本次更新

- PDF 预览移到标题、作者与引用键信息下方，居中显示并保留逐页翻阅按钮。
- 移除阅读时长与进度统计，聚焦文献整理、PDF 预览和引用导出；旧文库仍可加载。
- 重写项目首页，突出下载安装、主要功能、本地数据与集成方式。
- 修正自动保存回归测试的等待方式，保留从磁盘重新加载的校验，避免 CI 调度和对象生命周期导致误报。
- 统一应用、CLI 与 MCP 版本为 1.1.1。

## 下载与安装

需要 **macOS 14 或更新版本**，通用安装包同时支持 **Apple Silicon（arm64）与 Intel（x86_64）**。下载 `PaperManager-v1.1.1.dmg`，打开后将 **PaperManager.app** 拖入 **Applications**。

发行包使用临时签名（ad-hoc），尚未经过 Apple 公证；首次启动可能受到 macOS 安全机制拦截。此版本同时提供 `.sha256` 校验文件。

文库保存在本机。更新或批量整理附件前，可在设置中导出 `.papermanager` 备份。在线元数据查询需要联网，本地 API 默认关闭。
